**`agent_coop/gates.py`**（2 处实际代码修复，其余为已接受的 Codex 草稿）

   - 缺/`unknown` session → `missing runtime session identity: {role}`
   - `exit_code != 0` → `non-zero exit code: {role}`
   - adapter 不符 → `adapter mismatch for {role}`
   - model 不符 → `actual model differs from pinned profile: {role}`
   - 评审回执缺 `result` 对象 → `review receipt missing result object: {role}`

   公共门禁接口（`verify_gate`/`evidence`/`check_verdict`/`subject`/`validate_binding`/`cleanup_authority` 等）签名与语义均未变。
